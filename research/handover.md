# 引き継ぎメモ

ワークストリームごとに、今どこまで進んでいて、次に何をするかを書きます。自分の節だけを上書きしてかまいません。

## WS2 物理・記録 mod(2026-10-28)

- **済み**: 1.12.2 のプレイヤー物理(全ブロック、水と溶岩。ポータル類を除く)が公式コードと実機の両方でビット単位で一致(F-001, F-006)。`/mctas replay` で解答を実機再生できる(F-007)。解答ファイルにエンジンのビルド ID を書き、ID の違う解答の再生を拒否する。
- **進行中**: フルブロック設置(PR を出して実機確認待ち)。物理・公式コード照合(F-009, F-010)、問題形式 v2 の `player.inventory`、入力の `USE` と `slot`、mod の再生と照合(`/mctas fuzz place`、`/mctas replay` でホットバーを配る)まで実装済み。実機確認用の問題は `problems/place/01-pillar-2`。2 回目の実機ファズ(E-008)の唯一の不一致はサーバー側の設置判定(F-012)で、エンジンがサーバーの判定も見るように直した。3 回目(E-010)は設置の不一致 0。残ったのは、低い天井の下でスニークを離したときのサーバーの位置戻し(F-013、D-011)。
- **WS3 との取り決め**: `PlayerState.placed`(置いたブロックの差分、置いた順)、`state.world(base)` で差分を重ねたワールド、`equals` と `hashCode` は置いたブロックも含む、設置は (ワールド, 状態, 入力) だけで決まる。
- **保留**: mod の pitch が勝手に下がる現象(Q-003)。
