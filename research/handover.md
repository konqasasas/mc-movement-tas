# 引き継ぎメモ

ワークストリームごとに、今どこまで進んでいて、次に何をするかを書きます。自分の節だけを上書きしてかまいません。

## WS2 物理・記録 mod(2026-10-28)

- **済み**: 1.12.2 のプレイヤー物理(全ブロック、水と溶岩。ポータル類を除く)が公式コードと実機の両方でビット単位で一致(F-001, F-006)。`/mctas replay` で解答を実機再生できる(F-007)。解答ファイルにエンジンのビルド ID を書き、ID の違う解答の再生を拒否する。
- **完了**: フルブロック設置。実機確認済み(E-011 で不一致 0。ユーザー了承 2026-10-28)。物理・公式コード照合(F-009, F-010)、問題形式 v2 の `player.inventory`、入力の `USE` と `slot`、mod の再生と照合(`/mctas fuzz place`、`/mctas replay` でホットバーを配る)まで実装済み。実機確認用の問題は `problems/place/01-pillar-2`。2 回目の実機ファズ(E-008)の唯一の不一致はサーバー側の設置判定(F-012)で、エンジンがサーバーの判定も見るように直した。3 回目(E-010)は設置の不一致 0。残ったのは、低い天井の下でスニークを離したときのサーバーの位置戻し(F-013、D-011)。
- **WS3 との取り決め**: `PlayerState.placed`(置いたブロックの差分、置いた順)、`state.world(base)` で差分を重ねたワールド、`equals` と `hashCode` は置いたブロックも含む、設置は (ワールド, 状態, 入力) だけで決まる。
- **保留**: mod の pitch が勝手に下がる現象(Q-003)。

## WS5 ワールド取り込み(2026-10-28)

- **済み**: `mctas-problem import`(1.12.2 のセーブと `.schematic` から範囲を切り出して inline の問題ファイルに)、`mctas-problem diffworld`、mod の `/mctas mark`・`/mctas export`・`/mctas checkids`。数値 ID の表は 1.13 の変換表と一致(F-014)。v0 の 10 問をセーブに書いて取り込み直すと、ワールドも目標タイムも一致する(`WorldImportTest`)。コードは `problem/.../cli/importer/` にあり、エンジンのビルド ID には入らない(既存の解答はそのまま使える)
- **確認済み**: 実機での表の照合(E-012、F-016)。mod はユーザーの環境でビルド・動作した
- **確認済み**: セーブ取り込みとゲーム内書き出しが一致(E-013、F-017)
- **未確認**: 取り込んだ問題の解の実機再生(E-013 の残り)。探索(WS3)の解ができたら試す
- **方針**: 問題形式に `"source": "anvil"` は足さず、取り込みは inline の `fills` に書き出す。問題ファイルだけで完結し、セーブがなくても採点・再生できるため
