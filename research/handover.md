# 引き継ぎメモ

ワークストリームごとに、今どこまで進んでいて、次に何をするかを書きます。自分の節だけを上書きしてかまいません。

## WS2 物理・記録 mod(2026-10-28)

- **済み**: 1.12.2 のプレイヤー物理(全ブロック、水と溶岩。ポータル類を除く)が公式コードと実機の両方でビット単位で一致(F-001, F-006)。`/mctas replay` で解答を実機再生できる(F-007)。解答ファイルにエンジンのビルド ID を書き、ID の違う解答の再生を拒否する。
- **進行中**: フルブロック設置(PR を出して実機確認待ち)。物理・公式コード照合(F-009, F-010)、問題形式 v2 の `player.inventory`、入力の `USE` と `slot`、mod の再生と照合(`/mctas fuzz place`、`/mctas replay` でホットバーを配る)まで実装済み。実機確認用の問題は `problems/place/01-pillar-2`。
- **WS3 との取り決め**: `PlayerState.placed`(置いたブロックの差分、置いた順)、`state.world(base)` で差分を重ねたワールド、`equals` と `hashCode` は置いたブロックも含む、設置は (ワールド, 状態, 入力) だけで決まる。
- **保留**: mod の pitch が勝手に下がる現象(Q-003)。

## WS3 探索エンジン(2026-10-28)

- **済み**: `search` モジュール。上界はビームサーチ(`mctas-search beam`)、下界は抽象解釈(`mctas-search bound`)。v0 のうち 01・02・03・04・06・08・09 の最適を証明(F-013〜F-015)。09・10 の旧解の制約違反を見つけて差し替え(F-012)。
- **進行中**: 残り 3 問(05・07・10)の下界を締める。原因は、スタートの横の面から空中で入る状態を下界が許していること。区画を細かくするか、足場の端から跳んだ状態の位置と速度の相関を保つ表現にする。
- **未対応**: 天井、フルブロック以外、滑る床、持ち物(ブロック設置)は下界のモデルで Unsupported。
