# 教訓: WS11 逆向き探索(funnel)

作業を始める前に、[shared.md](shared.md) とあわせて全ワークストリームの教訓を読んでください。番号は振り直しません。古くなった教訓は消さずに、新しい項目で置き換えます。番号は 700 番台です。

- **L-701 ゴールへ向かう見積もりは、スタートから届くセルだけで作る。** 格子の上の楽観的な動きでは、木の上や壁の向こうなど、スタートからは行けない場所を通る近道ができ、その近道の先の足場から確かめ始めて時間を使い切った(waza1 h1)。前向きの見積もりで値の付いたセルに逆向きを限ると、確かめる順がスタートに向かう通路に沿う。
- **L-702 空中の状態は、格子の見積もりではなく、放物線の着地点で見積もる。** 格子の空中セル(ジャンプで届く範囲)を平地と同じに見ると、落ちている状態が「浮いて」ゴールに近づくように見え、ビームが崖から落ちる状態で埋まった。入力なしの放物線が各層を下りるところで、空中制御で届く範囲(ティックとともに広がる)の立てるセルの最小値を取る。届く範囲を大きく取りすぎると同じことが起きる。
- **L-703 ブロックの種類は、名前の状態(`[...]`)を外してから比べる。** はしご・水・マグマを名前の完全一致で探していて、状態つきの名前(`minecraft:ladder[facing=north]`)を見落とし、はしごを壁として扱っていた。
- **L-704 1x1 の足場は、止まった状態からでは確かめられないことがある。** 長い隙間の手前の 1x1 の足場は、前の足場からの速さを持ったまま跳ぶしかない。速さを持った仮の到着状態(スプリントで 0.30)と、ほかの足場のビームが実際にそこへ着地した状態の両方から確かめる。仮の状態だけでは、わずかに届かない跳びが残る。
- **L-705 助走(スタートに入る前)は判定の時計を 0 にするが、ビームの順位では少し数える。** 時計を「スポーンからのティック」にすると、助走の長いコースで、スタートに入る前の状態が最良の着地より遅く見えて刈られる。0 にすると今度は、スタートの箱を出入りして時計を 0 に戻し続ける状態がビームを埋める(v0 05-up-1)。順位では助走の 1 ティックを 0.6 と数える。
- **L-706 スタートに入る前の状態は、足場への着地として数えず、スタートへ向かわせる。** 助走の時計を 0 にしたら、スタートの箱を通らずに足場へ着いた状態が「時計 0 で着いた」として一番良い着地になり、前向きのつなぎ全体がスタートを通らない列になった(waza1 h1)。スタートに入る前は、スタートへの見積もり(×0.6)を順位に足し、着地を記録しない。
