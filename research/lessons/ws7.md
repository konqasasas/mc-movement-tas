# 教訓: WS7 物理高速化

作業を始める前に、[shared.md](shared.md) とあわせて全ワークストリームの教訓を読んでください。番号は振り直しません。古くなった教訓は消さずに、新しい項目で置き換えます。

- **L-301 座標を詰めた long を `HashMap` のキーにしない。** `Long.hashCode` は上位 32 ビットと下位 32 ビットを xor するので、x と z を詰めたキーは近くのブロックどうしで衝突し、検索が遅くなる(F-301)。ブロック参照は配列か、混ぜ合わせのよいハッシュのプリミティブな表で引く。速さを測るときは JFR のサンプリング(`-XX:StartFlightRecording`)で当たりをつける。
- **L-302 数秒を超えるテストには `@Category(Slow.class)` を付ける。** PR の CI は `./gradlew build` で速いテストだけを走らせ、遅いテストは main への push と夜間に `slowTest` で走る(F-302)。印のないまま重いテストを足すと、全員の PR が待たされる。PR で遅いテストも確かめたいときはラベル `full-tests` を付ける。
