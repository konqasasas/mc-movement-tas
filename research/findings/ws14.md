### F-1002 WS9 の stpt1 は、道筋を変えずに着地ごとに局所探索し直すだけで 210 → 195 になる。人間の 187 は同じ方法では縮まない
- 日付: 2026-10-29 / 構成: F-1001 と同じ、`tools/run-gap` の `Chain`(元の走りを 20 ティック以上離れた着地で 8 区間に切り、各区間を WS8 の `SegmentSearch`(幅 20000、最大 80 ティック)で「元の着地点から 1.5 ブロック以内の同じ高さの面への着地」まで探し、上位 2 本を次の区間に引き継ぐ。最後はゴールの箱)
- 測定:
  - WS9 の 210: 区間ごとに −6、−0、+2、−12、+2、−1、−3、+3 で 195(D-004 の違反なし、全体 4 分)。大きいのは天井の通路の区間(−12)と最初の区間(−6)で、F-1001 で遅れていた場所と同じ
  - 人間の 187: 197(+10)。累計の差は 3 区間目まで 0 か −3 だが、天井の出口の段差の区間で +1 になり、その先で +10 まで崩れる
  - 区間の出口を「平面を越える」(technique の `segment`)にした単独の探索では、人間の走りの区間でも −3 と −9 が出たが、そこからゴールまでつなぐと 187 と 193 で、縮まなかった
- 結論: stpt1 の WS9 の遅れ 23 のうち 15 は、今ある局所探索を WS9 の道筋に沿って当てるだけで取れる。人間の 187 は、この探索では縮まない(F-026、F-601 と同じ)。区間ごとの探索の「縮む」は、出口の状態が悪くなっても縮んだように見えるので、ゴールまでつないで確かめるまで数えない(L-1001)
- 解答: `/mnt/project-files/solutions/ws14/stpt1_ws9route_chain.tas`(195)
- ゲート: 1、2、3 / 実験: E-1002

### F-1003 区間ごとの下界との差(slack)は、縮められる場所を指さない。人間の stpt1 でも 4〜17 ある
- 日付: 2026-10-29 / 構成: main、`mctas-search segments`(40 ティックごと、WS3 の F-112)
- 測定: 人間の 187 の 5 区間の slack は 11、7、17、15、4(合計 54、区間の下界の和 133)。WS9 の 210 は 16、14、22、18、4(合計 74)。差が一番大きいのは人間でも天井の出口の段差を含む区間(17)
- 結論: 今の下界の slack は、ほとんどが下界の緩さ(段差・天井・はしごをまたぐ区間で大きい)で、縮められる量ではない。人間の走りがあるコースでは、同じ区間の slack を人間の slack と比べたときだけ意味がある。人間の走りがないコースで、slack の大きい区間に WS10 の作り直しを集中させる案(WS10 引き継ぎの 3)は、このままでは効かない見込み
- ゲート: 1、3 / 実験: E-1001

### F-1005 verdure: WS10 の 655 を着地ごとに局所探索し直すと、前半では 1〜6 ティック縮む場所があるが、つなぐと 680 に崩れる
- 日付: 2026-10-29 / 構成: F-1004 と同じ、`Chain`(20 ティック以上離れた着地で 25 区間、上位 2 本)と、着地ごとの 52 区間(8 ティック以上、上位 3 本)
- 測定:
  - 25 区間: 最初の 4 区間で −2、−2、−1、0(累計 −5)。5 区間目(k 100〜128。3 段を登りながら −x から −z へ曲がる)は、1 回の探索では着地が見つからず止まった
  - 52 区間: 累計の差は k 41 で −6、k 147 で −3、k 250 で −2、k 312 で −2 と前半は元より速いが、k 321 から遅れ始め(+5)、はしごの区間(k 347〜382)で +10、ゴールで 680(+25)。D-004 の違反なし
  - 区間の出口を平面にした単独の探索(24 区間)では、壁に当たる区間(k 52〜73)で 21 → 16(出口の速さ 0.07 → 0.26)、ほかに −9〜−11 の区間が 3 つ出たが、F-1002 のとおり、ゴールまでつないで確かめていない「縮む」は数えない
- 結論: 前半(k 0〜312)は、着地ごとの探索で数ティック縮む余地がある。とくにスタート直後(バニーホップ)と、壁に当たってスプリントが切れる跳び(k 65)。後半は WS10 の解の方が、1 区間ずつ一番速い着地を選ぶ探索より良い。貪欲に一番速い着地を選ぶと、出口の位置と速さが次の区間に合わなくなる(L-601 と同じ)ので、この方法はそのままでは解を作らない
- ゲート: 1、2、3 / 実験: E-1003
