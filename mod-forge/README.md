# mctas-recorder(Forge 1.12.2)

実際の Minecraft 1.12.2 でプレイヤーを入力どおりに動かし、毎ティックの状態を記録して、ヘッドレス物理エンジン(`physics`)の予測とビット単位で比べる Mod です。エンジン本体の照合(`oracle`)では確かめられない、クライアント側のキー処理・スプリント判定と、サーバーからの同期の影響を確かめるために使います。

入力を流し込む部分は `InputDriver` に分けてあり、あとで再生用 Mod の土台に使えます。

## 動かし方(Windows)

必要なもの: JDK 21(Gradle 用)。Minecraft 用の JDK 8 はビルド時に自動で取得されます。

```bat
cd C:\mc\mc-movement-tas\mod-forge
gradlew.bat runClient
```

初回は Minecraft と Forge のダウンロードで時間がかかります。起動したら:

1. 新しいワールドを作る: ゲームモードはサバイバル、ワールドタイプはスーパーフラット。
2. ワールドに入ったら、チャットで `/mctas fuzz 100` を実行します(100 本で約 20 分)。実行中は Minecraft を最小化せずに裏に置いたまま、ほかのウィンドウで作業してかまいません。Mod が実行中だけ「フォーカスを失ったらポーズ」を切るので、ゲームは止まらずに進みます(終わると元の設定に戻ります)。Minecraft のウィンドウの中でメニュー・チャット・インベントリを開くと、そのランは INVALID になります。足元の周囲 20 ブロック、高さ 56〜72 の範囲が書き換えられます。
3. 終わるとチャットに結果と記録ファイルの場所が出ます。`mod-forge\run\mctas\logs\` のファイルを送ってください。
4. ハーフブロックや階段などの確認は `/mctas fuzz shapes 100`、水と溶岩の確認は `/mctas fuzz fluids 100` です。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `/mctas fuzz [shapes\|fluids] [本数] [ティック数] [最初のシード]` | エンジンのテストと同じランダムコースを足元に作り、開始位置にテレポートしてランダム入力を流す。既定は 100 本、200 ティック、シード 1。`shapes` を付けると、勝手に変わるもの(砂、作物、感圧板など)を除いた 1.12.2 の全ブロックを使ったコース、`fluids` を付けるとそこに水か溶岩のプールを足したコースになる(水や溶岩はブロック更新なしで置くので、流れ出さない) |
| `/mctas script <ファイル>` | `.minecraft/mctas/scripts/<ファイル>` の入力列を今いる場所から流す。1 行 1 ティックで `キー ヨー ピッチ`(キーは W A S D、J=ジャンプ、R=スプリント、N=スニーク、なしは `-`) |
| `/mctas record` | 自分で操作したプレイを記録して照合する。`/mctas stop` で終了 |
| `/mctas stop` | 中断 |

## 記録の見方

1 ティック 1 行で、入力と実機の状態(double/float は 16 進で正確に)を書き、最後にエンジンの予測と一致すれば `ok`、違えば `DIFF <項目名>` を書きます。ずれたときはエンジンを実機の状態に合わせ直して続けるので、1 本の中で独立したずれを複数見つけられます。ティックの外で状態が変わったとき(サーバーからのパケットなど)は `# between ticks` として別に記録し、エンジンのずれには数えません。各ランの最後の `# result` 行に MATCH / MISMATCH / INVALID(未対応ブロックに触れた、押してくる動物などが近くにいた、実行中に画面を開いた、またはコースのブロックが走行中に変わった)が出ます。fuzz の間はワールドの `randomTickSpeed` を 0 にして(終わると元に戻ります)、草や作物、雪や氷がコースを変えないようにしています。

ティックの外の変化としてよく出るのは次の 2 つで、どちらもエンジンではなくサーバーとのやり取りによるものです。

- `sprinting`: サーバーはプレイヤーのフラグ(スニーク・スプリント)を約 1 ティック遅れで送り返してきます。スプリントやスニークを短い間に切り替えると、古い値で上書きされることがあります。
- `posX` など位置: サーバーが移動を受け付けず、前の位置に戻した(ブロックにめり込んだ状態から、さらにめり込む方向へ動いたときなど)。

## 前提

- オートジャンプは実行中だけ自動で切ります。
- fuzz 中はサーバー側でダメージを無効にし、満腹度を 20 に戻します(落下ダメージで速度が書き換わるのを避けるため)。
- クリエイティブでは動きません(飛行の切り替えが入るため)。
