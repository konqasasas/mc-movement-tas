# mc-movement-tas

Minecraft Java Edition 1.12.2 の移動TASを自動で探すエンジンです。ワールド、スタート直方体、ゴール直方体を与えると、最速ティック数とその全ティックの入力列を返すことを目標にしています。

## モジュール

| モジュール | 中身 |
| --- | --- |
| `problem` | 問題ファイル形式、スタートとゴールの判定、出力形式、問題集 |
| `physics` | ヘッドレスの 1.12.2 プレイヤー物理 |
| `mod-forge` | 実機 1.12.2(Forge)で入力を流し込み、毎ティック記録して `physics` と照合する Mod。独立した Gradle ビルド(`mod-forge/README.md`) |
| `search` | 最速タイムの探索。上界(正確な物理でのビームサーチ)と、証明つきの下界(状態集合の抽象解釈)(`search/README.md`) |
| `oracle` | 公式 1.12.2 jar のコードを直接動かし、`physics` とビット単位で照合する差分テスト(jar は `./gradlew :oracle:prepareMcpJar` で用意、無ければスキップ) |

## 研究メモ

スレッドどうしの知見の受け渡しは [research/](research/README.md) で行います。作業の前に [research/lessons.md](research/lessons.md) と [research/decisions.md](research/decisions.md) を読んでください。

## 問題と判定

問題ファイルの形式、スタートとゴールの判定、入力列と解答の形式は [docs/problem-format.md](docs/problem-format.md) にあります。問題集は `problems/` にあります。

```
./gradlew :problem:installDist
problem/build/install/mctas-problem/bin/mctas-problem time problems/v0/04-gap-3.problem.json problems/v0/04-gap-3.tas
```

## 実機で確認した制約(探索・再生の前提)

`physics` は実機のクライアント側の動きとビット単位で一致します(`mod-forge` の記録で確認)。ただしサーバーとのやり取りによって、エンジンの外で状態が変わることがあります。探索エンジンはこの節を前提にしてください。

### スプリントとスニークの切り替えは約 3 ティック空ける

サーバーはプレイヤーのフラグ(スニーク・スプリントなどを 1 バイトにまとめたもの)を、受け取ってから約 1 ティック遅れでクライアントに送り返します。スプリントかスニークを切り替えた直後の数ティックに、もう一度どちらかを切り替えると、古い値が届いてクライアントのスプリント状態が上書きされることがあります。届くタイミングはサーバーとクライアントのスレッドの都合で変わるので、エンジンでは再現できません(非決定的)。スプリント状態はスプリントジャンプの加速と空中加速に効くため、上書きされると再生した動きがずれます。

- 入力制約: スプリント状態またはスニーク状態が変わるティックどうしを、3 ティック以上空ける。スプリントは W・スプリントキーの離し押しだけでなく、壁に当たったとき(`collidedHorizontally`)にも自動で切れることに注意。
- 実機の記録では、ランダム入力 100 本で 46 回起きました。いずれもこの切り替えが 1〜2 ティック以内に続いた場合でした。

### ほかのエンティティに押された記録は無効

エンジンにはプレイヤー以外のエンティティがありません。動物やモブに押されると動きが変わるので、そうした記録は照合の対象外(`mod-forge` では INVALID)にします。

### ブロックにめり込んだ状態からの移動はサーバーに戻される

サーバーは移動を受け取るたびに、移動後の当たり判定(各辺 1/16 縮めたもの)がブロックと重なっていないかを調べます。移動前は重なっていなかったのに移動後に重なると、サーバーはプレイヤーを前の位置に戻します。クライアントの当たり判定は、すでにめり込んでいるブロックへさらに進むことを止めないため、めり込んだ状態から始めるとこれが起きます。普通のプレイではめり込まないので、スタート位置がブロックと重なっていなければ起きません。また、サーバー側で再計算した水平移動がクライアントと 0.25 ブロック以上ずれた場合も戻されます("moved wrongly")。

## ビルド

JDK 21 で `./gradlew build`(Windows は `gradlew.bat build`)。成果物は Java 8 向けにコンパイルされます。
